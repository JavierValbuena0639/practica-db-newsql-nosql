# Módulo NewSQL - Oracle SQL Developer 

## Descripción 
En esta sección se encuentran los scripts de SQL desarrollados en **Oracle SQL Developer**, enfocados en la definición, manipulación y consulta de datos relacionales estructurados. 

## Archivos Incluidos 
* `01_ddl_tablas.sql`: Creación de tablas, llaves primarias, foráneas e índices.
* `02_dml_datos.sql`: Inserción y actualización de registros de prueba.
* `03_consultas.sql`: Consultas con `JOIN`, agregaciones y filtros avanzadas.

## Instrucciones de Ejecución 
1. Abrir **Oracle SQL Developer** y conectar a la base de datos de práctica.
2. 2. Ejecutar los scripts en orden secuencial (`01_ddl_tablas.sql` ➔ `02_dml_datos.sql` ➔ `03_consultas.sql`).
