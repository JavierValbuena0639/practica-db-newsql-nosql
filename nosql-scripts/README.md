# Módulo NoSQL - MongoDB Compass 

## Descripción 

En esta sección se detallan las consultas y documentos desarrollados en **MongoDB Compass**, enfocados en la manipulación de datos semiestructurados sin esquema rígido (JSON/BSON). 

## Archivos Incluidos 
* `coleccion_datos.json`: Estructura inicial de documentos de prueba.
* `consultas_nosql.js`: Scripts de consulta (`find`), actualización (`$set`) y eliminación.
*  `agregaciones.js`: Pipelines de agregación (`$match`, `$group`, `$sort`).

## Instrucciones de Ejecución 
1. Conectar **MongoDB Compass** a la instancia local o clúster.
2. Importar la colección desde `coleccion_datos.json`.
3. Ejecutar las consultas y agregaciones indicadas en los archivos `.js`.
